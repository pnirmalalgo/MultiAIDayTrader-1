
# Multi AI Day Trader Chatbot

A sophisticated AI-powered chatbot for day trading strategies.  
It interprets user queries about stock tickers, date ranges, and trading strategies, generates Python code, executes it using Celery agents, and displays results on a Gradio UI (mounted on FastAPI) in the form of charts and tables.

---

## Features

### Agents

- **Interpreter Agent:**  
  Parses user queries and generates structured JSON containing ticker symbol(s), date range, and buy/sell strategy conditions.

- **Translator Agent:**  
  Converts the Interpreter Agent's output into detailed coding instructions, including which libraries to use, what indicators to plot, and what output files to generate.

- **CodeGen Agent:**  
  Generates Python code using instructions from the Translator Agent and structured JSON from the Interpreter Agent.

- **Advanced CodeGen Agent:**  
  Handles advanced user queries (e.g., additional buy/sell conditions) and generates Python code similarly to the CodeGen Agent.

- **Code Cleaner Agent (currently unused):**  
  Can review or clean code generated by CodGen/Advanced CodGen Agents in future updates.

- **Prompts File:**  
  Contains the base prompt for CodGen Agents (shared between CodGen and Advanced CodGen Agents).

> Note: All agents include Chain-of-Thought (CoT) reasoning for better decision-making.

---

## Orchestrator

The orchestrator handles routing and communication between all agents.

### Workflow:

1. Interpreter Agent parses the query.  
2. `market_data.py` loads required data from the SQLite database.  
3. Translator Agent generates coding instructions.  
4. Appropriate CodeGen Agent generates Python code.  
5. Celery executes the generated code asynchronously.  
6. Gradio UI polls for results and displays charts and tables.  
7. Orchestrator supports dynamic updates of Chain-of-Thoughts from the Interpreter Agent.

---

## Special Capabilities

- Generates Python code from natural language queries.  
- Executes code asynchronously using Celery workers.  
- Displays charts, tables, and metrics on Gradio UI.  
- Connects to internal database (`market_data.db`) for stock data.  
- Uses external APIs for fundamental and market data.

## Installation and Setup

### Prerequisites

Ensure **Conda** is installed.

```bash
source /opt/anaconda3/bin/activate multiaid_env
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Install Node.js (for Gradio UI):

```bash
brew install node
```

Ensure Homebrew path is set:

```bash
echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

Start Redis (if not already running):

```bash
brew install redis
brew services start redis
```

Create a `.env` file in the project root with:

```
FMP_API_KEY=your_fmp_api_key
OPENAI_API_KEY=your_openai_api_key
API_BASE_URL=http://localhost:8000
REDIS_URL=redis://localhost:6379/0
```

You can also use the `setup.sh` script to automate setup:

```bash
bash setup.sh
```

## Running the Application (Locally)

The system uses multiple services that can be run manually or via Docker.

### Using Docker

```bash
docker build -t daytrader-space:latest .
docker stop trading-agent
docker rm trading-agent
docker run -d -p 7860:7860 -p 8000:8000 --name trading-agent daytrader-space:latest
```

Once running, the application is accessible at:  
👉 **http://localhost:8000/**

### Without Docker (Manual)

Start Redis:

```bash
brew services start redis
```

Start Celery worker:

```bash
python -m celery -A tasks.executor worker --loglevel=info
```

Start FastAPI server:

```bash
uvicorn main:app --reload
```

Start Gradio UI (frontend):

```bash
npm start
```

Optional: Serve static files

```bash
python -m http.server 8000
```

## Example Usage

- “Test RELIANCE: buy RSI under 35, sell RSI over 65, last 6 months”

## Database and External Resources

- **External APIs:** (Add keys in `.env` file)

  - OpenAI GPT → For query interpretation and code generation

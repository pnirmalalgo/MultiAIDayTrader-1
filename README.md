Multi AI Day Trader Chatbot

A sophisticated AI-powered chatbot for day trading strategies.
It interprets user queries about stock tickers, date ranges, and trading strategies, generates Python code, executes it using Celery agents, and displays results on a Gradio UI in the form of charts and tables.

Features:

Agents:

Interpreter Agent:
Parses user queries and generates structured JSON containing the ticker symbol(s), start date and end date, and buy/sell strategy conditions.

Translator Agent:
Converts the interpreter agent's output into detailed coding instructions, including which libraries to use, the coding approach, which indicators to plot, and what output files to generate.

CodGen Agent:
Generates Python code using instructions from the Translator Agent and structured JSON from the Interpreter Agent.

Advanced CodGen Agent:
Handles advanced user queries (such as additional buy conditions) and generates Python code similarly to the CodGen Agent.

Code Cleaner Agent (currently unused):
Can review or clean code generated by CodGen/Advanced CodGen Agents in future features.

Prompts File:
Contains the base prompt for CodGen Agents. Shared between CodGen and Advanced CodGen Agents.

Note: All agents have Chain-of-Thoughts (CoT) implemented to allow reasoning and better decision-making.

Orchestrator:

The orchestrator handles routing and communication between all agents. The workflow is as follows:

1) Interpreter Agent parses the query.

2) Ticker lookup and market_data.py loads the required data from the SQLite database.

3) Translator Agent generates coding instructions.

4) Appropriate CodeGen Agent generates Python code.

5) Celery executes the generated code.

6) Gradio UI polls for results and displays charts and tables.

7) The orchestrator also supports dynamic updates of Chain-of-Thoughts from the Interpreter Agent.

Special Capabilities:

Generates Python code based on natural language queries.

Executes code asynchronously using Celery.

Displays outputs dynamically on the Gradio UI in the form of charts, tables, and performance metrics.

Connects to an internal database (market_data.db) for historical stock data and fundamental metrics.

Installation and Setup:

Ensure Conda is installed.

Activate your Conda environment:

source /opt/anaconda3/bin/activate multiaid_env


Install Python dependencies:

pip install -r requirements.txt


Install Node.js if not already installed:

brew install node


Ensure Homebrew path is set in your .zshrc:

echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc


Install and start Redis if not already installed:

brew install redis
brew services start redis


Create a .env file in the project root with your FMP API key and OpenAI GPT API key.

You can also run the setup.sh script to automate all of the above:

bash setup.sh

How to Run:

The system involves multiple services that run in parallel:

Start Redis:

brew services start redis


Start the Celery worker:

python -m celery -A tasks.executor worker --loglevel=info


Start the FastAPI server:

uvicorn main:app --reload


Start the Gradio UI (frontend):

npm start


Start HTTP server (optional, for static files):

python -m http.server 8000


All services can also be started automatically via setup.sh.

For easier debugging, you may run each service in a separate terminal.

Default Gradio URL: http://127.0.0.1:7860/

Example Usage

Some example queries that demonstrate the chatbot’s capabilities:

"Test RELIANCE: buy RSI under 35, sell RSI over 65, last 6 months"

"Compare RSI performance of NIFTY Total: same parameters, 2 years"

"Test Nifty 500: buy when 20-day MA crosses above 50-day MA, sell on reverse crossover, last 18 months"

Queries are interpreted, Python code is generated, executed, and results are displayed dynamically on the Gradio UI.
